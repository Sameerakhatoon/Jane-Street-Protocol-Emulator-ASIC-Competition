# first edge again; at 4 MHz (3.5 MHz at 50 MHz) it gets there after that edge and the first bit
# of the next byte is lost, so these are R314 (fix f_sck <= 1.99 MHz). The sequencer reference
# model loses that bit in every slot phase at 4 MHz and 3 MHz. With bytes back to back the first
# edge after CS also needs t_css >= 117 ns (the lane drives MISO and sets its counter first).
